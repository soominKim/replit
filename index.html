데이터베이스 : 글자와 숫자를 저장하는 공책

고객사 이름, 미팅 메모, 생성한 문구처럼 글자와 숫자로 된 것을 저장합니다. 앱마다 공책(PostgreSQL)이 한 권씩 들어있습니다.
말하는 법 : "입력한 메모를 데이터베이스에 저장하고 목록에서 다시 보게 해줘"

App Storage : 사진과 파일을 넣는 서랍

공책(데이터베이스)에 사진을 붙일 수는 없습니다. 이미지·PDF·영상은 App Storage라는 서랍에 넣고, 공책에는 "서랍 몇 번 칸"만 적어둡니다.
말하는 법 : "업로드한 이미지는 App Storage에 저장하고 갤러리에서 보여줘"

첫 프롬프트 : 저장소 두 개와 AI 두 종을 이름으로 지정

뉴스 기사나 보도자료 텍스트를 붙여 넣으면 마케팅 콘텐츠를 자동으로 만들어주는 웹앱을 만들어줘.
결과물 : 3줄 요약, LinkedIn 게시글, 인스타그램 캡션(해시태그 포함), 사내 뉴스레터용 한 문단.
톤은 "정중한 B2B" / "친근한 SNS" 두 가지 중 선택.
결과마다 어울리는 대표 이미지 1장을 AI로 생성해서 함께 보여줘.
텍스트는 데이터베이스에, 이미지는 App Storage에 저장하고, 갤러리에서 지난 결과를 다시 볼 수 있게.
텍스트 생성은 OpenAI gpt-5.6-luna, 이미지 생성은 Google gemini-2.5-flash-image. Replit AI Integrations 사용.
처음 열었을 때 데이터가 없으면 샘플 결과 2개를 자동으로 채워 넣어줘.
로그인 없이 누구나 사용, 한국어 UI, 깔끔한 업무용 디자인, 모바일 대응.
"데이터가 없으면 샘플 결과 2개" 줄이 게시 후 빈 화면을 막는 보험입니다. 모델명은 공식 문서의 표기를 그대로 씁니다.
참고 · 관리자 페이지 추가하기

런칭 후에는 사용자 입력과 운영 데이터를 분리합니다

런칭 후에는 사용자가 보내는 요청과 실제 서비스에 노출되는 데이터가 함께 움직입니다. 이 둘을 한 화면에서 다루면 아직 검증하지 않은 입력이 바로 운영 데이터처럼 보일 수 있습니다. 관리자 화면 하나로 그 경계를 만듭니다.
관리자 운영 화면을 만들려고 한다.
/admin 경로에 관리자 전용 페이지를 추가해줘. 관리자로 지정한 이메일 목록에 있는 사람만 들어갈 수 있게.
관리자 화면에서는 사용자가 생성한 콘텐츠 목록을 최신순으로 보고, 각 항목을 검토 대기 · 공개 · 숨김 중 하나로 바꿀 수 있어.
일반 사용자 화면(갤러리)에는 공개 상태인 항목만 보여줘. 새로 생성된 항목의 기본값은 검토 대기.
관리자는 항목을 수정·삭제할 수 있고, 삭제는 확인창을 거쳐. 누가 언제 무엇을 바꿨는지 변경 로그를 표로 남겨줘.
일반 사용자 화면에는 관리자 메뉴가 보이지 않게 해줘.
핵심은 세 가지입니다 : 누가 들어오나(관리자 이메일 목록) · 무엇이 보이나(상태값으로 노출 제어) · 무엇을 했나(변경 로그). 메이커톤 이후 현업 파일럿 단계에서 붙이면 됩니다.

로그인은 한 문장, 또는 버튼 하나로 붙습니다

지금 앱에 Replit Auth로 로그인 기능을 추가해줘.
로그인한 사용자만 자기 결과를 저장하고 다시 볼 수 있게. 로그인 없이도 첫 화면과 샘플 결과는 볼 수 있어야 해.
로그인 버튼은 우상단에, 로그인 후에는 이름과 로그아웃 버튼을 보여줘.

제공자(Google · GitHub · X · Apple · 이메일)는 같은 화면의 Configure에서 켜고 끕니다
사용자는 Replit 계정으로 로그인하게 되므로, 오늘 메이커톤 제출물에는 넣지 않습니다
